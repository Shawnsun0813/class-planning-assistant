# 首版候选独立评审

日期：2026年11月11日（America/New_York）。评审对象：当前工作区应用及 `http://127.0.0.1:5173/` 实际运行候选。评审者未编写或修改业务代码、数据和需求。

## 结论

**可交付为有明确限制的首版试用候选。** 本轮发现的四项 P1 和两项 P2 均已修复并在相应范围复验，当前没有遗留的已复现交付阻塞。

这不代表完整 PRD 的所有验证均已通过。实际大模型推理、竞价策略有效性、完整官方竞价规则及同学采用价值仍未验证；不得将其表述为已验证的自动竞价产品。

## 评审范围与证据

先依据用户原要求、START-HERE、PRD、首位用户案例和设计约定形成判据，再检查实际数据、代码及独立 Chromium 流程。工程作者报告的构建和测试成绩不是本评审的替代证据。

- 独立读取官方 Spring 2027 课程接口，对比目录的245条课程：标题、学期、起止日期、学分和原始课时字段一致。
- 运行 `python3 scripts/validate_data.py`，检查源文件哈希、记录数、真实554分数、课程号复用、零与缺失、异常表名及分离的数据用途。
- 独立调用真实数据上的参考和预算函数，核对 PM 的固定 Round 3、`reported_round_value` 样本为258、263、410，参考中位数为263；新651没有同课参考，也没有自动填入预算数。
- 独立 Chromium 首轮实际操作九项核心检查；修复后仅重测新增问题及受影响的导入、恢复和执行边界。
- 未占用共享桌面浏览器，未登录学校系统、提交选课或出价、发布站点或联系同学。

原始记录及截图位于 [`artifacts/review/`](../artifacts/review/)。最终针对性复验的代码指纹和结果见 [`retest-evidence.json`](../artifacts/review/retest-evidence.json)。

## 实际交互检查

首轮独立操作确认：

1. 真实课程资料载入，无页面脚本错误。
2. 22学分历史基线保留“未确认”，retreat等未知项可见。
3. 移除554先产生18学分讨论分支，明确采纳后才更新，撤回可恢复基线。
4. S2的651-02与878-01冲突时阻止采纳。
5. 新651缺同课历史时不自动给分；预算超额时保留输入并禁止保存。
6. 损坏备份拒绝导入且原状态保持；不同本地方案不串条件。
7. 默认浏览器无WebGPU时明确提示模型未调用，没有假模型回答或付费回退。
8. 390px实际页面没有整页横向溢出；视觉详细复核另由设计者负责。

新增问题修复后的针对性实际操作确认：

- 临时非法预算刷新不丢方案，同时仍阻止无效预算执行。
- 可编辑草稿能够恢复；结构损坏的备份仍被拒绝。
- 真正损坏的缓存主存储及恢复副本逐字保留；下载内容与原文完全相同；编辑临时恢复方案不会静默覆盖原文。
- 导入有效恢复备份后，只有明确点击继续才替换主缓存；恢复原文副本仍保留。
- 未解析课程原引用保留在当前与讨论方案及备份中；部分合计有说明，完整采纳和ICS均受阻。
- 导入的已确认但时间不完整的硬限制仍被执行校验拦截，缓存恢复放宽不会静默忽略该限制。

上述独立浏览器流程未捕获页面脚本错误。首轮证据中的失败记录保留为修复历史；最终状态以针对性复验记录为准。

## 交付时必须保留的限制

- 本环境未取得可用WebGPU adapter，真实WebLLM模型下载和推理未验证。已验证的是明确失败提示与规则功能继续可用；不能声称AI推理通过。
- 竞价总分由使用者输入；“落选退分”是用户提供规则。单课上限、具体轮次、平分与扣分机制、主动退课退款等仍未获完整官方核实。预算草案不等于官方可提交策略或未来中标保证。
- 历史数据为聚合记录，不支持未经验证的成功概率。新课、不同课程名称及语义不明的Round列须保持现有标记。
- 课程目录是快照；资格和先修需要个人核对。常规课表不覆盖全部假期、retreat及其他特殊承诺。
- 本地多方案用于分别整理，不是账号鉴权或访问控制；同浏览器使用者可访问本地方案，没有云同步。
- 多人长期访问仍需要合适部署。当前仅验证运行候选，没有执行正式公开发布，也没有实际同学采用或竞价效果试验。
