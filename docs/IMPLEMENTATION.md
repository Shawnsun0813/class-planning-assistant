# 首版实施与运行证据

版本：0.1｜2026年11月11日｜实施任务 ENGINEER-01。

## 运行入口

当前工作区运行 `npm run dev`，监听 `0.0.0.0:5173`。本地入口为 http://localhost:5173/ 。这是工作区试用服务，不是持续托管或正式公开部署。

```sh
npm ci --cache /tmp/som-npm-cache
npm run dev
npm run test
npm run test:e2e
npm run build
```

`npm run test:e2e` 使用 `/usr/bin/chromium`，端口5173已有服务时复用，否则自动启动 Vite。其他机器可在 `playwright.config.ts` 中调整浏览器路径。普通 npm 缓存目录在本环境不可写，示例使用临时目录，不要求全局安装。

## 已实施路径

- React、TypeScript、Vite 单页工作台，探索课程／课表与方案／竞价建议三个页内区域；中文操作、英文课程标题。
- 读取 `data/catalog.json` 的官方2027春目录，以及历史竞价、选课人数、交换与跨院资料和公开体验背景材料。交换与跨院资料不混入普通课程竞价。
- 搜索课程、学段／课程范围筛选、查看来源与资格、比较课程；文本关联明确不是质量或求职结果评分。
- 个人学分、硬时间限制、限定课程／学段的例外、小组与retreat等其他时间承诺；确认条件后生成有界搜索候选，不静默放宽限制。
- 全学期／S1／S2常规时间检查，缺时间课程不加入生成器；资格未核实清楚标记为候选。
- 首位用户历史基线及18／20学分讨论分支；明确采纳前保留差异，采纳可撤回，课程变化后预算重新计算。已有非空方案重新导入案例会建立新本地方案，保留原决定。
- 按同课程号与规范化课程标题匹配历史；课程编号复用不混用。同教学班优先，按同一轮次与同一字段含义分组参考。没有同课参考不自动给分；参考小于可用预算时保留余额。
- 用户输入总预算和已占用分，检查非负整数及超支；只保存预算分配草案。落选退分为用户提供规则，退课退款、轮次和单课限制仍待核，不自动执行跨轮退款。
- 本地独立命名方案、当前个人方案JSON备份导入／导出、常规课程ICS导出。个人选择仅存浏览器，不需要付费API。

## 免费模型的实际状态

集成 `@mlc-ai/web-llm` 的真实动态加载与聊天调用，模型为 `Qwen3-0.6B-q4f16_1-MLC`。用户主动点击后才检查GPU并下载；不创建密钥，不调用OpenAI或其他付费API。模型仅解释现有证据，不直接改方案或出价。

本环境真实 Chromium 有 `navigator.gpu`，但无法取得GPU adapter。实际点击启用返回“没有可用WebGPU”，界面清楚提示模型未调用；规则功能继续工作。**模型下载和生成未在此环境验证通过，不能声称大模型已完成端到端验收。** 首次下载约数百MB，兼容浏览器和硬件要求见 [WebLLM官方说明](https://webllm.mlc.ai/docs/user/basic_usage.html)。

免费模型引擎为按需独立代码块，生产构建提示该块较大；常规课表功能不等待模型下载。未实现付费或伪造的降级模型。

## 限制

- 普通竞价规则未获完整官方核验；预算分配是明确假设下的草案，不是验证过的策略，也没有中标概率。
- 所有个人资格、先修及retreat等缺失事项仍需核对。候选通过常规时间检查不等于学校确认可报名。
- 每段“涉及学分”包括活跃的全学期课程，明确提示不是官方学分拆分，不可将S1／S2相加。
- 日历按目录日期范围展开常规课时，学校假期、临时变更和特殊活动需另核；没有日期或时间的课不导出虚构事件。
- 方案保存在浏览器本地，不是账号安全隔离、多人协作或云同步。共享电脑上的其他使用者可能看到本地方案；可分别在个人设备使用并导出备份。
- 自动生成是有限宽度搜索；未找到组合不能证明全部组合都无解。课程工作量和学习效果不从课名伪造。
- 尚未正式部署，未发送邀请，未向学校提交选课或竞价。

## 独立评审后的恢复修复

预算和学分等有限数值草稿允许持久化，合法性在计算／采纳时校验；不会因总预算暂时低于已用分而丢掉整份课表。真实E2E覆盖100／10改成5／10并刷新，22学分7门及错误输入仍保留。结构损坏缓存保留原文与recovery备份，明确继续前不覆写；未知课程引用逐项显示并保留，不能被静默略过后当成完整课表采纳或导出ICS。

生产产物单独以4173端口运行验证：实际Chromium载入245条官方课程、渲染155个选修教学班、载入历史基线后显示22学分7门，页面错误为0。证据为 `artifacts/production-smoke.json` 和 `artifacts/production-preview.png`。5173试用服务未停止或替换。
