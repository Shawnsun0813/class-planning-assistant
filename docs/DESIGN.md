# Yale SOM 选课助手核心页面设计

版本：0.1｜2026年11月11日｜任务：DESIGN-01。

本轮已获准进入首版实施。本文定义一个可体验的选课工作台，实施者负责代码和运行；实际页面的视觉与交互验收仍待运行后执行。当前没有设计截图，也没有已完成的界面验收。

## 核心方向

以“我现在有哪些课程，准备改什么，改完会怎样”为主要任务。页面不是宣传页。课程推荐、半学期课表和竞价依据服务于同一份个人方案，不另造多学期规划或社交入口。

使用中文操作文案，课程名保留原英文。左上名称为“SOM Course Planner”，辅以“选课与竞价工作台”。不使用校徽或“官方”字样，身份说明采用“面向 Yale SOM 同学的选课辅助”。

首屏要看见四件事：当前学期和资料范围、方案状态、已选课程与学分、影响可行性的未核实项。没有确认方案时不能出现“最新已确认课表”。

## 一个核心页面

桌面版建议最大内容宽度1440px，页边24px；顶部为页头和方案栏，下方左侧约300px条件栏，右侧为工作区。空间不足时条件栏移到工作区上方，不压缩长课名。

### 页头和方案栏

- 页头显示产品名称、项目／学期、资料更新情况；右侧保留“导入／导出”和帮助入口。
- 学期显示真实资料对应范围。导入案例中的2027春季须显示“历史案例标注，待核对”，不能默认为已验证的当前学期。
- 方案栏显示名称和状态，例如“历史导入方案 · 待确认”。旁边显示学分合计及其验证状态，避免把标称22学分写成已核实合计。
- 三种状态直接使用文字：“历史导入”“讨论方案”“已确认”。颜色辅助识别，不作为唯一信息。
- 存在未采纳修改时显示“查看修改差异”；提供明确的“采纳此方案”与“放弃修改”。普通课程问答或选择比较项不会自动采纳。

### 左侧条件栏

按使用顺序分三组，默认只展开必要输入：

1. **资料范围。** 当前课程、历史竞价、评价和其他表格分别显示已载入／部分可用／待接入；可查看来源和覆盖学期。不能把上传成功当作已正确解析。
2. **我的条件。** 不可上课时段、已选／必选课、学分范围；每项区分硬限制和偏好。提供少量可增删时间行，避免只有一段不可表达复杂约束的自由文本。
3. **选课取舍。** 求职或学习方向、工作量偏好、预算和已占用分数。职业方向可多选或补充，不要求先完成长测评。

从历史恢复的条件集中显示“请核对”，已有字段可编辑；“确认这些条件”后才用于宣称约束通过。允许仅确认已核对项，未确认内容保留未知状态。

S1／S2例外紧邻对应条件显示，例如“仅S1，允许MGT652在周四延后”。不会通过一个全局“忽略冲突”按钮放宽全部约束。

### 右侧工作区

采用三个普通页内标签：“课程探索”“课表与方案”“竞价建议”。标签保留同一份个人输入和讨论状态，切换不重置表单。

**课程探索**：顶部搜索课程号、课名或教师，配学段筛选。结果采用可展开行或低密度卡片。折叠态至少显示课程号、长标题、学段、学分、上课时间及资料状态；展开后显示推荐原因、学习增量／重叠、作业与工作量证据、评价来源和历史竞价依据。提供“比较”“加入讨论方案”“排除”，避免一个含糊的“选课”按钮被误解为向学校报名。

长内容样例使用真实案例中的标题，如“Building Adaptive Enterprises: Supply Chains, Geopolitical Risks, and National Security”和“Impact Investing: The Role of Private Capital in Driving Social Change”。标题不以固定一行省略；课程号独立显示便于扫视。

**课表与方案**：顶部提供S1／S2切换；全学期课程同时进入两段视图。周历仅显示对应学段的时间，班级块含课程号、可换行短名和起止时间；点击查看完整记录。周历下始终保留课程列表，不能只能靠彩色日历块辨认课程。

资料缺少正式日期时，标题写“按现有周次资料预览”，不能宣称整个学期已通过。必修小组、retreat及其他活动作为课程列表中的“其他时间承诺”；未知日期／约略时间显示原状。空白周五标“无已知常规课程”，不标“完全空闲”。

底部放“需要处理”区域，列出时间冲突、资格未知、特殊活动待核及资料矛盾。区分“已发现冲突”与“尚不能核验”，不要混成一个红色错误。

**竞价建议**：先显示总预算、已占用、当前分配及剩余。下方表格展示课程、参考学期／轮次、历史记录含义、参考值、建议值或区间和当前采用值。桌面表格在窄屏改为逐课记录。

没有可靠规则或样本时，对应格写“暂不能估计”，说明缺少什么。历史门槛明确标为历史参考，不能包装成未来成功概率。预算超过限制时，保留输入并指出超额数；只阻止采纳这份无效预算，不阻断课程浏览、草稿保存或修正。是否允许退分仅按规则显示，不能从改课动作自动推定。

## 修改和讨论的交互

1. 课程比较或提问先显示依据和选择，例如“保留554”与“移除554的讨论方案”。
2. 加入或移除产生讨论分支。修改差异展示新增／删除课程、学分变化、S1／S2时间变化、冲突和预算影响；未知项继续显示未知。
3. 用户明确采纳后更新确认方案，并提供“撤回上次修改”。多处修改可作为一次可理解的方案采纳，不要求每个点击弹确认框。
4. 22／18／20学分是来源不同、未采纳的历史方案关系。导入时分别保留，不能顺序叠加。没有确认记录时，查询“最新课表”先展示导入基线和未决分支说明。
5. 导出至少区分“个人方案备份”与“课表摘要”；文件注明学期、方案状态和待核事项。讨论方案导出不能去掉状态标记。

## 视觉取值

| 用途 | 建议值 |
| --- | --- |
| 页面底色 | #F5F6F8，低对比浅灰 |
| 卡片底色 | #FFFFFF |
| 主要文字 | #172332 |
| 次要文字 | #526173，关键状态不用浅灰小字隐藏 |
| 主操作与链接 | #00356B，深蓝 |
| 待核提示 | 深棕文字#79520A配浅金底#FFF5D9 |
| 冲突提示 | 深红文字#A32932配浅红底#FFF0F1 |
| 边线 | #D8E0E8 |
| 已确认状态 | 深绿文字#25604B配浅绿底#EAF5EF |

使用系统无衬线字体，优先Inter、系统UI字体、中文系统字体；不增加必须联网加载的字体依赖。正文14至16px，次要信息不少于12px，主标题24至28px。表单控件高度约40px，正文行高1.5至1.6。卡片间距16至20px，内容内边距20px，圆角10至12px。只保留轻边线和极淡阴影，不堆叠渐变、玻璃效果或动画背景。

周历可用少量区分色，但仍显示课程文字、状态和图例；同一门课跨学段保持同色。主操作每个区域只突出一个。禁用态同时解释原因，焦点轮廓清晰可见。

## 窄屏和辅助操作

建议在900px以下转单栏。390px宽度下不让整页横向滚动；周历切为按星期分组的时间列表，保留S1／S2切换。不是把五天周历强行缩到手机宽度。

课程长标题与评价摘要自然换行；预算表转逐课卡片，数字及单位同行。主要按钮可全宽但不要遮住底部内容。表单均有可见标签，键盘焦点按视觉顺序移动；标签页支持键盘操作，焦点不随重算丢失。状态变化有文字反馈，减少动态效果时禁用非必要过渡。

## 必要状态

| 状态 | 页面行为 |
| --- | --- |
| 首次使用，无个人方案 | 显示建立方案入口；可主动载入“首位用户历史案例”，不把案例个人偏好默认为每位同学条件 |
| 数据加载 | 显示正在处理的来源名称，保留已输入条件；不伪报课程或记录数量 |
| 文件解析失败 | 指出文件与可识别原因，保留其他成功资料和个人输入，允许重新导入 |
| 没有搜索结果 | 展示当前筛选，提供清除筛选，不伪造课程补空 |
| 约束无解 | 列出具体冲突与可选修改，不静默放宽硬条件 |
| 资格或时间缺失 | 列为待核候选，可比较；不能标“已验证可选” |
| 评价缺失或只有传闻 | 明示缺少可靠评价；新课仍可比较，不把缺评价记成低分 |
| 免费模型不可用 | 明示未调用模型，保留真实数据与规则解释；不显示伪造聊天回复或偷偷切换付费服务 |
| 重算／采纳成功 | 列出本次变化及还待核对的事项，避免含糊的“全部成功” |

## 运行后设计验收

实施者提供实际入口后，由设计者检查1440px桌面与390px窄屏，以及长英文标题、零结果、缺数据、时间冲突、预算超额和模型不可用状态。实际操作一次载入、条件确认、比较、生成讨论方案、采纳和撤回；查看截图只能说明外观，不能替代交互核查。
